# Code of conduct

This is a short document because the project is small. It is not an adaptation
of the Contributor Covenant; if you would rather work under that, say so in an
issue and it can be adopted.

## What is expected

Discuss the work. A report that says a measurement is wrong is welcome; one that
says the person who took it is careless is not, and it is also less useful,
because it gives nothing to check.

Assume the other person had a reason. Most of what looks like carelessness in
this codebase turns out to be a decision made under a constraint that is no
longer visible — which is why so many of the comments here explain why rather
than what.

Take correction the same way. Being shown wrong is how the defects in this
package got found, including several introduced by whoever was most confident.

## What is not acceptable

Harassment, insults, or personal attacks. Sustained disruption of a discussion.
Publishing someone's private information. Unwelcome attention of a sexual
nature.

None of this depends on who is involved or how long they have been around.

## Scope

This applies in issues, pull requests, commit messages and anywhere else the
project is being worked on, including where someone is representing the project
elsewhere.

## Reporting

Through a private GitHub security advisory, which is the only private channel
this repository has:

https://github.com/jorgell23-sys/mdcx/security/advisories/new

Reports are read by the maintainer. What happens next depends on what happened:
it may be a conversation, a request to change something, or removal from the
project's spaces. A report made in good faith will not count against the person
making it, whatever the outcome.
